## About

I'm an Internet of Things student interested in the engineering behind intelligent systems: how models learn, how data moves through a pipeline, and how to make experiments reproducible. I learn best by building things, testing assumptions, and documenting what I find.

Right now, my focus is **machine learning, neural networks, local AI, and quantum computing tools**. I'm still early in the journey, so I try to keep project claims grounded in what the code actually does.
